# Data-Professional-Survey-Dashboard
A dynamic and interactive Power BI dashboard designed to analyze survey responses from data professionals worldwide. The dashboard provides insights into job roles, salary, programming language preferences, work-life balance, demographics, and country-wise participation, helping users understand trends in the data analytics industry.

📌 Short Description / Purpose

The Data Professional Survey Breakdown Dashboard is an interactive Power BI report that visualizes survey data collected from professionals working in various data-related roles. It helps users explore salary trends, job distributions, programming language preferences, work-life satisfaction, and demographic insights to better understand the current landscape of the data industry.

🛠 Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Used for creating interactive reports and dashboards.
📂 Power Query – Used for data cleaning, transformation, and preprocessing.
🧠 DAX (Data Analysis Expressions) – Used to create calculated measures and KPIs.
🔗 Data Modeling – Built relationships between survey data fields for effective filtering and analysis.

📂 Data Source

Source: Data Professionals Survey Dataset

The dataset contains responses from 630 data professionals across multiple countries. It includes information such as:

Job Title
Country
Age
Salary
Gender
Favorite Programming Language
Work-Life Balance Rating
Salary Satisfaction Rating

The dataset is structured as a single survey table, making it suitable for data transformation, analysis, and visualization.

✨ Features / Highlights
📌 Business Problem

Organizations, students, and aspiring data professionals often struggle to understand:

Which data roles offer higher salaries?
Which programming languages are most popular?
How satisfied are professionals with their work-life balance?
Which countries have the highest survey participation?
What demographic trends exist within the data industry?

Raw survey data makes answering these questions difficult.

🎯 Goal of the Dashboard

The dashboard aims to:

Analyze salary trends across different job roles.
Compare survey participation by country.
Identify the most popular programming languages.
Understand work-life balance and salary satisfaction.
Explore demographic insights such as age and gender.
Enable interactive filtering for deeper analysis.
